# پروژه ساخت APK برنامه مدیریت کافه

این بسته شامل وب‌اپ فعلی و تنظیمات لازم برای تولید APK آزمایشی با GitHub Actions است.

## ساخت APK فقط با گوشی
1. فایل ZIP را در گوشی دانلود و استخراج کن.
2. یک مخزن جدید در GitHub بساز و فایل‌های داخل این پوشه را در آن بارگذاری کن (Upload files).
3. در مخزن GitHub، به زبانه Actions برو و workflow با نام **Build Android APK** را اجرا کن. در صورت نیاز ابتدا Actions را فعال کن.
4. پس از پایان موفقیت‌آمیز ساخت، وارد اجرای workflow شو و از بخش Artifacts فایل `cafe-price-app-debug-apk` را دانلود کن.
5. ZIP مربوط به Artifact را باز کن؛ فایل `app-debug.apk` داخل آن است. آن را روی گوشی نصب کن. ممکن است اندروید برای نصب از منبع ناشناس اجازه بخواهد.

## محدودیت‌ها
- این بسته به‌خودی‌خود APK نیست؛ ابزار ساخت ابری آن را می‌سازد.
- برای ساخت و دریافت APK باید حساب GitHub داشته باشی و مخزن را خودت بارگذاری کنی؛ من از اینجا به حساب تو دسترسی ندارم و نمی‌توانم workflow را به‌جای تو اجرا کنم.
- این یک APK آزمایشی debug است، نه نسخه انتشار امضاشده.
- این نسخه شامل قابلیت‌های فعلی پروژه وب است. تنظیمات پیشرفته لوگو/فونت و سربرگ/پاورقی که در گفتگو طراحی کردیم، و ورود واقعی کاربران، هنوز پیاده‌سازی نشده‌اند.
- اطلاعات برنامه فعلاً روی همان دستگاه/حافظه محلی ذخیره می‌شود؛ پشتیبان‌گیری JSON را مرتب انجام بده.
